**VoxRox Mail 0.2.0**, an e-mail client for Windows. This is the stable release of 0.2.0-beta.4: the same application, now offered to every installation, not only to those on the Beta channel.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **From 0.1.0, install it by hand once.** Versions 0.1.0 and 0.2.0-beta.1 trust only the retired signing key and cannot take this version through the updater. Installations of 0.2.0-beta.2 and later update on their own.

## Highlights

- New mail is announced with a Windows notification while the window is hidden in the notification area or behind another application. It gives the number of messages, the account and the folder, never the sender or the subject, and **Nastavení → Vzhled** turns it off
- Microsoft work or school accounts and Google Workspace accounts can be added
- Forwarding keeps the attachments; a new message adds files with **Ctrl+Shift+A**, shows their total size against the limit and skips a file attached twice
- Senders whose images you chose to always load are listed in the account's settings under **Obrázky z internetu**, and each can be removed. In the Spam folder their images no longer load on their own
- Better to use with a screen reader and the keyboard: the account forms read clearly, the focused item in every menu and in the command palette is outlined, and subfolders show under their parent folder with the Inbox first

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

On 0.2.0-beta.2, 0.2.0-beta.3 or 0.2.0-beta.4, accept the update when the application offers it, or choose **Zkontrolovat aktualizace** in **Nastavení → O aplikaci**. On 0.1.0 or 0.2.0-beta.1, run the installer over your installation. Either way it keeps your mail, accounts and settings and needs no administrator rights. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [END_USER_README.md](https://github.com/TheVoxRox/mail/blob/main/frontend/END_USER_README.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
