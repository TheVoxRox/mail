The first beta of **VoxRox Mail 0.2.1**, an e-mail client for Windows. It reaches installations that chose the **Beta** channel; everyone else stays on 0.2.0 until this version is promoted.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **It updates on its own from 0.2.0-beta.2 on.** An installation of 0.2.0, or of 0.2.0-beta.2 to 0.2.0-beta.4, on the Beta channel offers this version through the updater. An installation of 0.1.0 or 0.2.0-beta.1 trusts only the retired signing key and installs this one by hand.

## Highlights

- A Microsoft account is added through **Přihlásit přes Microsoft** alone. Microsoft refuses passwords over IMAP, app passwords included, so the forms no longer ask for one
- A Gmail app password works however it was pasted or typed, with Google's spaces or without them
- A mail server whose Let's Encrypt certificate comes without its intermediate can now be added and synced
- When an account needs a new sign-in, the notice names the account, says that its new mail has stopped, and links straight to **Nastavení, Účty**
- Keyboard and screen reader: each toolbar over a message is one Tab stop with the arrow keys inside, the account switcher changes account only on Enter, the grouped list announces a conversation once per arrow key, and error messages are in the interface's language

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

On 0.2.0, or on 0.2.0-beta.2 to 0.2.0-beta.4, with the Beta channel chosen, accept the update when the application offers it, or choose **Zkontrolovat aktualizace** in **Nastavení → O aplikaci**. On 0.1.0 or 0.2.0-beta.1, run the installer over your installation. Either way it keeps your mail, accounts and settings and needs no administrator rights. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [END_USER_README.md](https://github.com/TheVoxRox/mail/blob/main/frontend/END_USER_README.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
