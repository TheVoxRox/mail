The first version of **VoxRox Mail**, an e-mail client for Windows. There is no need to install Java; it comes with the application.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

## Highlights

- Gmail, Outlook and standard IMAP/SMTP accounts, several side by side
- Conversations across folders, full-text search and an address book
- Outlook-style keyboard control and full screen-reader support
- Your mail and passwords stay on your computer

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

The installer needs no administrator rights. This is the first version, so it is a fresh install; the application offers later versions itself when it starts.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [END_USER_README.md](https://github.com/TheVoxRox/mail/blob/main/frontend/END_USER_README.md) describes.
