The third beta of **VoxRox Mail 0.2.1**, an e-mail client for Windows. It reaches installations that chose the **Beta** channel; everyone else stays on 0.2.0 until this version is promoted.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **It updates on its own from 0.2.0-beta.2 on.** An installation of 0.2.1-beta.2, 0.2.1-beta.1, 0.2.0, or 0.2.0-beta.2 to 0.2.0-beta.4, on the Beta channel, offers this version through the updater. An installation of 0.1.0 or 0.2.0-beta.1 trusts only the retired signing key and installs this one by hand.

## Highlights

- Sending a message with large attachments no longer takes several times their size in memory on its way to the mail service
- A burst of log output, as on a troubled start, no longer overwrites an older log file, so **Uložit logy** keeps the earlier logs
- The record the application writes at each start names the state of every database update, which helps diagnose an update that failed
- Updated components underneath, among them one named in a security advisory that does not apply on Windows

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

On 0.2.1-beta.2, 0.2.1-beta.1, 0.2.0, or 0.2.0-beta.2 to 0.2.0-beta.4, with the Beta channel chosen, accept the update when the application offers it, or choose **Zkontrolovat aktualizace** in **Nastavení → O aplikaci**. On 0.1.0 or 0.2.0-beta.1, run the installer over your installation. Either way it keeps your mail, accounts and settings and needs no administrator rights. Coming from a version older than 0.2.1-beta.2, the first start after the update backs up the database and then updates it, so it takes a moment longer than usual. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [Verifying the installer](https://github.com/TheVoxRox/mail/blob/main/docs/VERIFYING_THE_INSTALLER.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
