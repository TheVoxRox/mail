**VoxRox Mail 0.2.1**, an e-mail client for Windows. This is the stable release of 0.2.1-beta.3: the same application, now offered to every installation, not only to those on the Beta channel.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **From 0.1.0, install it by hand once.** Versions 0.1.0 and 0.2.0-beta.1 trust only the retired signing key and cannot take this version through the updater. Installations of 0.2.0 and of every beta from 0.2.0-beta.2 on update on their own.

## Highlights

- Contacts are found by their name however it is typed: with or without diacritics, in any case, and by the full name in either order, in the address book and in the suggestions of the compose window. The address book sorts Č among the C names
- An e-mail address is checked by one rule as you type it in the compose, contact and account forms, so a typo such as `jan.@seznam.cz` is marked at once instead of the send failing after it has started
- Spaces pasted around a name, a username or a subject are no longer stored with it. Contacts and accounts already saved are cleaned on the first start after the update
- Search says what it searched, the mail downloaded to this computer, so an empty result no longer reads as "the message does not exist"
- A Microsoft account is added through **Přihlásit přes Microsoft** alone, a Gmail app password works with Google's spaces or without them, and a mail server whose Let's Encrypt certificate comes without its intermediate can now be added and synced
- When an account needs a new sign-in, the notice names the account, says that its new mail has stopped, and links straight to **Nastavení, Účty**
- Sending a message with large attachments no longer takes several times their size in memory, and **Uložit logy** keeps the earlier logs after a burst of log output
- Keyboard and screen reader: each toolbar over a message is one Tab stop with the arrow keys inside and fits a 1366-pixel screen, the grouped list announces a conversation once per arrow key, and error messages are in the interface's language

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

On 0.2.0, or on any beta from 0.2.0-beta.2 on, accept the update when the application offers it, or choose **Zkontrolovat aktualizace** in **Nastavení → O aplikaci**. On 0.1.0 or 0.2.0-beta.1, run the installer over your installation. Either way it keeps your mail, accounts and settings and needs no administrator rights. Coming from a version older than 0.2.1-beta.2, 0.2.0 among them, the first start after the update backs up the database and then updates it, so it takes a moment longer than usual. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [Verifying the installer](https://github.com/TheVoxRox/mail/blob/main/docs/VERIFYING_THE_INSTALLER.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
- In the dialog that merges contacts, a screen reader does not say why **Sloučit kontakty** is unavailable when the merged contact would go over a limit. The reason is written just above **Zrušit**, and the merge does not run.
