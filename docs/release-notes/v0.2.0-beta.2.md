The second beta of **VoxRox Mail 0.2.0**, an e-mail client for Windows. It reaches installations that chose the **Beta** channel; everyone else stays on 0.1.0 until this version is promoted.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **Install this one by hand.** Updates are now signed with a new key, so an installation of 0.1.0 or 0.2.0-beta.1 cannot take this version through the updater. Run the installer over your installation; updates after this one arrive through the updater again.

## Highlights

- Updates are signed with a new key, kept apart from the build that produces the installer, so a compromised build tool can no longer sign an update
- A published release can no longer be changed afterwards: the installer you download is the one that was released
- The components that check for updates, start the mail service and keep a single window open are updated

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

Run the installer over your installation of 0.1.0 or 0.2.0-beta.1. It installs over the existing installation and keeps your mail, accounts and settings, and it needs no administrator rights. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [END_USER_README.md](https://github.com/TheVoxRox/mail/blob/main/frontend/END_USER_README.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
