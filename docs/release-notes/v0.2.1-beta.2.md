The second beta of **VoxRox Mail 0.2.1**, an e-mail client for Windows. It reaches installations that chose the **Beta** channel; everyone else stays on 0.2.0 until this version is promoted.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

> **It updates on its own from 0.2.0-beta.2 on.** An installation of 0.2.1-beta.1, of 0.2.0, or of 0.2.0-beta.2 to 0.2.0-beta.4, on the Beta channel offers this version through the updater. An installation of 0.1.0 or 0.2.0-beta.1 trusts only the retired signing key and installs this one by hand.

## Highlights

- Contacts are found by their name however it is typed: with or without diacritics, in any case, and by the full name in either order, in the address book and in the suggestions of the compose window. The address book sorts Č among the C names and a name in lower case next to the same name with a capital
- An e-mail address is checked by one rule as you type it in the compose, contact and account forms, so a typo such as `jan.@seznam.cz` is marked at once instead of the send failing after it has started
- Spaces pasted around a name, a username or a subject are no longer stored with it: no more doubled space in the contact list, no stray space in the sender of every message, no username the server refuses. Contacts and accounts already saved are cleaned on the first start after the update
- Search says what it searched, the mail downloaded to this computer, so an empty result no longer reads as "the message does not exist"
- The toolbar over an open message no longer runs off the edge of a 1366-pixel screen, checkboxes and scrollbars are dark in the dark theme, and a list that fits on one page shows only its count

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

On 0.2.1-beta.1, on 0.2.0, or on 0.2.0-beta.2 to 0.2.0-beta.4, with the Beta channel chosen, accept the update when the application offers it, or choose **Zkontrolovat aktualizace** in **Nastavení → O aplikaci**. On 0.1.0 or 0.2.0-beta.1, run the installer over your installation. Either way it keeps your mail, accounts and settings and needs no administrator rights. The first start after the update backs up the database and then updates it, so it takes a moment longer than usual. Going back to an older version afterwards is not possible: the installer refuses it.

The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [Verifying the installer](https://github.com/TheVoxRox/mail/blob/main/docs/VERIFYING_THE_INSTALLER.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at once; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
