The first beta of **VoxRox Mail 0.2.0**, an e-mail client for Windows. It reaches installations that chose the **Beta** channel; everyone else stays on 0.1.0 until this version is promoted.

> **Closed beta.** Gmail signs in only with an account on the tester list. The application runs on Windows only for now.

## Highlights

- Subfolders show under their parent folder, and folders come in a fixed order with the Inbox first
- Forwarding keeps the attachments; a new message adds files with **Ctrl+Shift+A**, shows their total size against the limit and skips a file attached twice
- Microsoft work or school accounts and Google Workspace accounts can be added
- More of Outlook's keys: **Backspace** archives, **Ctrl+Shift+I** goes to the Inbox, and Mail comes back to the folder you left
- The application starts faster, and writing a message with large attachments no longer slows it down

All changes: [CHANGELOG.md](https://github.com/TheVoxRox/mail/blob/main/CHANGELOG.md)

## Install or update

To get this version on an installation of 0.1.0, choose **Beta** under **Nastavení → O aplikaci → Kanál aktualizací** and then **Zkontrolovat aktualizace**. The update installs over the running application and keeps your mail, accounts and settings. Going back to 0.1.0 afterwards is not possible: the installer refuses an older version.

A fresh install needs no administrator rights. The installer is not signed, so Windows reports an unknown publisher. Before running it through **More info → Run anyway**, verify the downloaded file as [END_USER_README.md](https://github.com/TheVoxRox/mail/blob/main/frontend/END_USER_README.md) describes. How releases will be signed: [Code signing policy](https://github.com/TheVoxRox/mail/blob/main/CODE_SIGNING_POLICY.md).

## Known issues

- Gmail signs in only with an account on the tester list (see the closed beta note above).
- An occasional transient failure to connect to the IMAP server. Sync recovers on its own in the next cycle, and no mail is lost.
- A mail server that sends extremely large answers can still make the mail service run out of memory when two such accounts sync at the same time; it then restarts on its own. No data leaves your computer. If that happens three times in a row, the sync of that account pauses until you choose **Synchronizovat**.
